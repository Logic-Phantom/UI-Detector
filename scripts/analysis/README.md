# Analysis Scripts

이 디렉토리는 YOLO 모델과 데이터셋을 분석하는 스크립트들을 포함합니다.

## 파일 목록

### analyze_labels.py
- **라벨 분석**: YOLO 데이터셋의 라벨 분포 분석
- **특징**: 클래스별 분포, 데이터셋 통계 정보
- **사용법**: `python analyze_labels.py`
- **출력**: `label_analysis_result.txt`

### model_diagnosis.py
- **모델 진단**: YOLO 모델의 성능과 상태 진단
- **특징**: 모델 정확도, 손실 함수, 훈련 상태 분석
- **사용법**: `python model_diagnosis.py`
- **출력**: 모델 진단 리포트

## 주요 기능

1. **데이터셋 분석**: 라벨 분포, 클래스별 통계
2. **모델 성능 분석**: 정확도, 손실, 훈련 상태
3. **결과 시각화**: 차트, 그래프로 분석 결과 표시
4. **리포트 생성**: 분석 결과를 텍스트 파일로 저장

## 분석 항목

### 라벨 분석
- 클래스별 데이터 개수
- 라벨 분포 시각화
- 데이터셋 불균형 확인

### 모델 진단
- 훈련/검증 정확도
- 손실 함수 변화
- 모델 가중치 분석
- 과적합/과소적합 진단

## 출력 형식

- **텍스트 파일**: 분석 결과 요약
- **PNG 파일**: 분석 결과 시각화
- **CSV 파일**: 상세 분석 데이터
